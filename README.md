# 🚀 Setup and Run the To-Do-List App
1. Extract the Files: Right-click the TodoList.zip file. Select Extract All... (Windows) or double-click it (Mac) to unzip the folder. Please make sure all three files (index.html, script.js, and styles.css) are sitting in the same folder.

2. Open the HTML File: (There are two ways to view your app)

Method A (Direct): Locate index.html in your file explorer and double-click it. It will open in your default web browser (Chrome, Firefox, etc.)

Method B (Drag & Drop): Open your browser first, then drag the index.html file from your folder and drop it into an empty browser tab.

3. Verify it's working: Once the page loads, you can test the functionality, like adding a task, checking/unchecking, refreshing the page to see if the data is still in the browser, and clearing all data. 

Pro Tip for Development
If you plan on editing the code, I recommend using VS Code with the Live Server extension. This automatically refreshes your browser every time you save a change, so you don't have to manually click refresh.
